Projects I've worked on

Alien Parapocalypse

A 2D action shooter inspired by Space Invaders, featuring a wheelchair-based protagonist with ranged and melee mechanics.
Designed multiple enemy behaviors including path-following aerial units, projectile attackers, kamikaze units, and melee-only ground enemies.
Focused on dynamic combat patterns and varied enemy AI behaviors to create layered gameplay encounters.

TRex Game

A JavaScript remake of the Chrome offline dinosaur game with custom movement and collision logic.
Implemented core gameplay systems including jump physics and obstacle generation.
The game includes a custom time-step system, though it behaves inconsistently across different devices due to scaling differences.

Memory Madness

A digital memory card game featuring a custom deck and randomized card generation system.
Implemented logic to ensure balanced pair generation and restricted player interaction to two active selections at a time.
Designed and created a custom visual card set using Adobe Illustrator and Photoshop.

Super Fruit Slasher

A fast-paced competitive reaction game where players race to slice fruits while avoiding hazards.
Developed systems for randomized object generation, collision detection, and synchronized dual-player interactions.
Includes a scoring system and timed reaction mechanics with penalty states for incorrect actions.

Nerfir Protocol

A 3D alien shooter developed in Unreal Engine 5 as an early group project.
I worked on gameplay scripting and level interactions, including trigger-based events and enemy behavior systems.
The project explored early 3D shooter mechanics and level design in Unreal Engine.

Meireki no Hikeshi

A historical firefighting game set during the Meireki fire of Edo-era Japan.
I implemented core gameplay systems including movement, interaction mechanics, and fire-extinguishing gameplay loops.
The project focused on translating historical context into interactive gameplay mechanics.
